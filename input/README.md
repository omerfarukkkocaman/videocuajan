# input/

Her video için bir klasör aç: `input/<proje>/`

```
input/kahve-tarifi/
  konu.txt   konu, hedef kitle, istekler (isteğe bağlı)
  video/     konuşan kafa / vlog / ekran kaydı
  ses/       ayrı seslendirme (kendi sesin)
  broll/     ara görüntü klipleri (projenin yönünde)
  gorsel/    logo, fotoğraf, ekran görüntüsü
```

Bu klasörün içeriği git'e **girmez**; videoların yalnız senin bilgisayarında kalır. En kolayı Claude Code'a `/basla` yazmak, klasörü o hazırlar.
